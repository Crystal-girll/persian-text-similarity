# Contributing

Small, reproducible issues and pull requests are welcome. Include the input,
expected result, Python version, and an offline regression test when relevant.
Use synthetic or openly licensed text; never upload client material or secrets.

Run `python -m unittest discover -s tests -v` before submitting. Keep the baseline
dependency-free and document behavior changes. Semantic changes should identify
the model, model revision, dataset license, and evaluation method. Follow a
respectful, constructive tone in issues and reviews.
